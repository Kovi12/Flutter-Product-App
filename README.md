# Flutter product application

A Flutter product-browser prototype with login/registration, product cards, search and detail navigation.

Authentication uses Firebase Auth. Firestore integration is in progress: the product screen declares a Firestore stream but currently renders a local sample list.

Use the Flutter SDK and `pubspec.yaml`, configure your own Firebase project or emulator and database rules, and provide the referenced image assets. Keep account configuration and credentials local. Run from the Flutter workspace after restoring any platform scaffolding needed by your target.

University mobile/IoT coursework.
